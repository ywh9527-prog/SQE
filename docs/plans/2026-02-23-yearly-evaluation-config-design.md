# 年度绩效评价配置系统设计方案

## 1. 概述

为实现年度绩效评价与月度/季度评价的完全隔离，需要创建独立的配置系统。

## 2. 架构设计

### 2.1 配置文件分离

| 配置文件 | 用途 |
|---------|------|
| `evaluation-config.json` | 月度/季度评价配置 |
| `yearly-evaluation-config.json` | 年度评价配置（新建） |

### 2.2 数据模型扩展

在评价周期表中增加 `type` 字段：
- `monthly` - 月度评价
- `quarterly` - 季度评价
- `yearly` - 年度评价

### 3.2 维度类型区分

| 类型标识 | 评价行为 |
|---------|---------|
| `auto` 自动计算 | 自动读取该供应商全年月度评价的对应维度分数，取平均值 |
| `manual` 手动评分 | 显示输入UI，用户手动填写分数 |
| `green` 绿色环保 | 勾选是否合格，不合格一票否决 |

## 5. 评价总分计算

### 5.1 计算公式

```
总分 = Σ(各维度分数 × 权重)
```

### 5.2 一票否决机制

当绿色环保为"不合格"时：
- 无论总分多少，等级强制判定为"不合格"
- 评价详情中记录一票否决原因
